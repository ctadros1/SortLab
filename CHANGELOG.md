# Changelog

All notable changes to SortLab are documented here.

## 1.0.0 — 2026-07-14

- Added an event-driven sorting visualizer with forward and backward step history.
- Added 36 algorithms across exchange, selection, insertion, merge, partition, heap, distribution, network, hybrid, and novelty families.
- Added seeded dataset generation, validated custom input, sound, live statistics, narration, pseudocode highlighting, and safety caps.
- Added synchronized two-way comparison, a searchable learning catalog, a complexity-growth explainer, and cancellable Web Worker benchmarks.
- Added light, dark, and system themes; keyboard controls; reduced-motion behavior; and responsive desktop, tablet, and mobile layouts.
- Added automated correctness tests, hardened Nginx delivery, Docker Compose deployment, documentation, and Arcane-compatible project discovery.
